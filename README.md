## // projects

### [nullscan](https://github.com/nullps1/nullscan)
Fast cross-platform network and port scanner written in Rust. Supports concurrent TCP scanning, service banner grabbing, vulnerability detection, and multiple export formats. MIT licensed with Linux and Windows binaries available.

### [logslueth](https://github.com/nullps1/logslueth)
Regex-powered log analyzer with severity-aware colorized output. Built in Rust for quickly scanning, filtering, and understanding log files without friction.

### [lead-generator](https://github.com/nullps1/lead-generator)
CLI tool that finds local businesses, analyzes website quality, and exports scored leads to Excel. Python-based tool for identifying outreach and redesign opportunities.
